# Defense Speech from Presentation

`Language: EN` `Academic presentations` `Source file: Текстова доповідь.md`

## What This Prompt Is

A Ukrainian prompt for creating a 5-7 minute defense speech from an attached presentation.

## Purpose

Use it to turn slide content into a coherent oral defense script.

## What You Can Generate

- Defense speech script
- Slide-by-slide narration
- Timing-aware wording

## Expected Results

- More coherent oral delivery
- Better slide transitions
- Clearer defense timing

## Inputs to Prepare

- Presentation file
- Defense duration requirement

## How to Use

- Open the language version you need.
- Copy the full prompt block.
- Attach the files or links expected by the prompt.
- After the first run, fill in any variables or clarifications requested by the model.

## Prompt

<details open>
<summary>Prompt text</summary>

~~~markdown
Analyze the attached presentation.
Your task is to create a textual report for a 5-7 minute defense based on the data for each slide in the presentation. The presentation style is scientific-technical.
Take a deep breath and start the task as responsibly as possible.
Without [cite_start] and other [cite].
~~~

</details>
