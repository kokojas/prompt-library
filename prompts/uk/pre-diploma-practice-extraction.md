# Промпт витягу зі звіту з переддипломної практики

`Language: UK` `Промпти для витягу` `Source file: Звіт з переддипломної практики_для витягу.md`

## Що це за промпт

Український промпт для дослівного витягу заданих розділів зі звіту з переддипломної практики.

## Для чого саме

Використовується для витягу вихідного тексту для подальшого збирання роботи або суміжного документа.

## Що можна отримати

- Дослівний витяг розділу
- Збережене форматування
- Текстовий блок для подальшої роботи

## Очікувані результати

- Менше випадкового переписування
- Чистіше подальше збирання
- Краща простежуваність джерела

## Що підготувати

- Файл звіту з переддипломної практики
- Потрібні розділи

## Як використовувати

- Відкрийте потрібну мовну версію.
- Скопіюйте блок промпту повністю.
- Додайте файли або посилання, які промпт очікує як вхідні дані.
- Після першого запуску уточніть змінні, які модель попросить конкретизувати.

## Промпт

<details open>
<summary>Текст промпту</summary>

~~~markdown
Ти працюєш з файлом "ЗВІТ З ПЕРЕДДИПЛОМНОЇ ПРАКТИКИ". 
Твоє завдання — витягти вказані нижче розділи тексту без змін, зберігши оригінальне форматування, у форматі MD.

Витягни наступну частину:
1. "РОЗДІЛ 3. ОСНОВНІ ЕТАПИ ВИДІЛЕННЯ ТА ОЧИЩЕННЯ ЦІЛЬОВОГО ПРОДУКТУ" (повністю, включаючи всі підрозділи 3.1 - 3.5 та схему/рисунок, якщо є). Це піде у РОЗДІЛ 8 фінальної роботи.

ВАЖЛИВА УМОВА: У тексті цього розділу є посилання на літературу (наприклад (Bodo et al., 2017) або (PMC, 2020) або [12]). Ти повинен зберегти ці цитування у тексті без жодних змін. Після витягнутого тексту створи заголовок "СПИСОК ВИКОРИСТАНИХ ДЖЕРЕЛ ДЛЯ ЦЬОГО БЛОКУ" і випиши туди з оригінального списку літератури (який є в кінці документа) ТІЛЬКИ ті джерела, які згадуються у витягнутому тобою тексті. Бібліографічний опис джерел залишай в оригінальному вигляді без змін.
~~~

</details>
