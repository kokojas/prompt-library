# Промпт витягу з курсового проєкту про доферментаційні процеси

`Language: UK` `Промпти для витягу` `Source file: Курсовий проєкт "Ділянка доферментаційних процесів"_для витягу.md`

## Що це за промпт

Український промпт для витягу з курсового проєкту про доферментаційні процеси та виробничий біосинтез.

## Для чого саме

Використовується для дослівного копіювання заданих розділів проєкту для подальшого збирання роботи або звіту.

## Що можна отримати

- Дослівні витяги розділів проєкту
- Збережене форматування
- Матеріал, узгоджений із джерелом

## Очікувані результати

- Надійніше повторне використання розділів
- Менше випадкового перефразування
- Чіткіші межі витягу

## Що підготувати

- Файл курсового проєкту
- Потрібні розділи

## Як використовувати

- Відкрийте потрібну мовну версію.
- Скопіюйте блок промпту повністю.
- Додайте файли або посилання, які промпт очікує як вхідні дані.
- Після першого запуску уточніть змінні, які модель попросить конкретизувати.

## Промпт

<details open>
<summary>Текст промпту</summary>

~~~markdown
Ти працюєш з файлом "Курсовий проєкт «Ділянка доферментаційних процесів та виробничий біосинтез...»". 
Твоє завдання — витягти вказані нижче розділи тексту без змін, зберігши оригінальне форматування, у форматі PDF.

Витягни наступні частини:
1. "РЕФЕРАТ" та "ВСТУП" повністю.
2. "РОЗДІЛ 1. ТЕХНІКО-ЕКОНОМІЧНЕ ОБҐРУНТУВАННЯ" (повністю, від початку до кінця розділу). Це піде у РОЗДІЛ 3 фінальної роботи.
3. "РОЗДІЛ 2. ОБҐРУНТУВАННЯ ВИБОРУ ДОПОМІЖНИХ СТАДІЙ ВИРОБНИЦТВА" (повністю). Це піде у РОЗДІЛ 5 (п. 5.2-5.6) фінальної роботи.
4. "РОЗДІЛ 3. СПЕЦИФІКАЦІЯ ОБЛАДНАННЯ ДЛЯ ВИРОБНИЦТВА..." (повністю з таблицею). Це піде у РОЗДІЛ 6 фінальної роботи.
5. "РОЗДІЛ 4. ОПИС ТЕХНОЛОГІЧНОЇ СХЕМИ ВИРОБНИЦТВА..." (повністю). Це піде у РОЗДІЛ 7 фінальної роботи.
6. "РОЗДІЛ 5. Контроль виробництва" (повністю). Це піде у РОЗДІЛ 9 фінальної роботи.

ВАЖЛИВА УМОВА: У тексті цих розділів є посилання на літературу у квадратних дужках (наприклад, [1], [15-18]). Ти повинен зберегти ці номери у тексті без жодних змін. Після витягнутого тексту створи заголовок "СПИСОК ВИКОРИСТАНИХ ДЖЕРЕЛ ДЛЯ ЦЬОГО БЛОКУ" і випиши туди з оригінального списку літератури (який є в кінці документа) ТІЛЬКИ ті джерела, номери яких зустрічаються у витягнутому тобою тексті. Бібліографічний опис джерел залишай в оригінальному вигляді без змін.
~~~
