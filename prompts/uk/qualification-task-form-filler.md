# Заповнення бланка завдання на кваліфікаційну роботу

`Language: UK` `Бланки кваліфікаційної роботи` `Source file: Мета-промпт_завдання.md`

## Що це за промпт

Український промпт для заповнення бланка завдання на кваліфікаційну роботу за бланком, прикладом і даними роботи.

## Для чого саме

Використовується для створення заповненого бланка завдання у стилі DOCX зі збереженням інституційного форматування.

## Що можна отримати

- Заповнений бланк завдання
- Мапінг даних по полях
- Нотатки щодо форматування

## Очікувані результати

- Швидша підготовка адміністративних документів
- Менше пропущених полів
- Ближча відповідність прикладам

## Що підготувати

- Порожній DOCX-бланк
- Заповнений DOCX-приклад
- Структуровані дані роботи

## Як використовувати

- Відкрийте потрібну мовну версію.
- Скопіюйте блок промпту повністю.
- Додайте файли або посилання, які промпт очікує як вхідні дані.
- Після першого запуску уточніть змінні, які модель попросить конкретизувати.

## Промпт

<details open>
<summary>Текст промпту</summary>

~~~markdown
Твоє завдання: заповнити бланк завдання на кваліфікаційну роботу.

Вхідні файли:
1. Бланк завдання DOCX.
2. Файл-приклад заповнення DOCX.
3. Загальні дані здобувача у текстовому форматі.

Формат виводу: DOCX.
Назва вихідного файлу: Завдання_{Прізвище}.docx

Перед генерацією перевір, чи є всі потрібні дані:
- ПІБ здобувача повністю;
- точна тема кваліфікаційної роботи;
- ПІБ керівника;
- науковий ступінь / посада / вчене звання керівника;
- вихідні дані до роботи;
- зміст пояснювальної записки;
- перелік графічного матеріалу (необхідна лише кількість сторінок у форматі А1 по апаратурній схемі та технологічній схемі);
- календарний план або достатньо даних для його формування.

Якщо хоча б одного поля немає, не створюй DOCX. Чітко напиши, яких саме даних бракує.

Правила заповнення:
- Заповнюй саме бланк, не створюй документ з нуля.
- Зберігай структуру, таблиці, поля, інтервали, шрифт (Times New Roman) та форматування бланку.
- Файл-приклад використовуй для стилю формулювання таких розділів:
  - “Вихідні дані до роботи”;
  - “Зміст пояснювальної записки”;
  - “Перелік графічного матеріалу”;
  - “Календарний план”.
- Не копіюй із прикладу чужі ПІБ, тему, біологічний агент, продукт, дати чи графічні матеріали.
- Номер і дата наказу сталі: наказ 199кс від 30.03.2026.
- У переліку графічного матеріалу вказуй лише технологічну схему та апаратурну схему. Не додавай схему біотрансформації або інші матеріали, якщо вони прямо не вказані користувачем.
- Таблицю “Консультанти розділів роботи” не заповнюй.
- Дотримуйся форматів імен:
  - ПРІЗВИЩЕ ім’я по батькові здобувача у курсиві;
  - “Керівник…” — ПРІЗВИЩЕ ім’я та по батькові керівника у курсиві;
- У календарному плані текст етапів має бути нежирним.
- Наприкінці документа в рядках підписів вказуй лише ім’я та ПРІЗВИЩЕ здобувача і керівника у курсиві.
- Назви мікроорганізмів, наприклад Aspergillus niger, виділяй курсивом у всьому документі.
- Жирне форматування назв полів, як у бланку, не переноситься на вставлений текст у пропусках. Якщо поле має жирний заголовок, вставлений зміст після нього має бути звичайним, якщо приклад явно не вимагає іншого.
~~~

</details>
