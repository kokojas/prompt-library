# Промпт витягу з першої курсової роботи

`Language: UK` `Промпти для витягу` `Source file: Курсова робота_найперша_для витягу.md`

## Що це за промпт

Український промпт для витягу вибраних розділів із ранньої курсової роботи.

## Для чого саме

Використовується, коли попередню курсову потрібно використати як джерело зі збереженням оригінального тексту.

## Що можна отримати

- Точні витяги з джерела
- Повторно використовувані текстові фрагменти
- Збережене форматування розділів

## Очікувані результати

- Чистіше використання старої роботи
- Менший ризик переписування
- Керованіше перенесення джерела

## Що підготувати

- Файл попередньої курсової
- Список цільових розділів

## Як використовувати

- Відкрийте потрібну мовну версію.
- Скопіюйте блок промпту повністю.
- Додайте файли або посилання, які промпт очікує як вхідні дані.
- Після першого запуску уточніть змінні, які модель попросить конкретизувати.

## Промпт

<details open>
<summary>Текст промпту</summary>

~~~markdown
Ти працюєш з файлом "Курсова робота...". 
Твоє завдання — витягти вказані нижче розділи тексту без змін, зберігши оригінальне форматування, у форматі MD.

Витягни наступну частину:
1. "РОЗДІЛ 3. ХАРАКТЕРИСТИКА БІОЛОГІЧНОГО АГЕНТА" (повностю, підрозділи 3.1, 3.2, 3.3, 3.4). Це піде у РОЗДІЛ 2 (п. 2.3, 2.4) фінальної роботи.

ВАЖЛИВА УМОВА: У тексті цього розділу є посилання на літературу у квадратних дужках (наприклад, [16], [17], [24]). Ти повинен зберегти ці номери у тексті без жодних змін. Після витягнутого тексту створи заголовок "СПИСОК ВИКОРИСТАНИХ ДЖЕРЕЛ ДЛЯ ЦЬОГО БЛОКУ" і випиши туди з оригінального списку літератури (який є в кінці документа) ТІЛЬКИ ті джерела, номери яких зустрічаються у витягнутому тобою тексті. Бібліографічний опис джерел залишай в оригінальному вигляді без змін.
~~~

</details>
