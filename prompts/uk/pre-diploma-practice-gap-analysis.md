# Аналіз нестач даних у звіті з переддипломної практики

`Language: UK` `Звіти з практики` `Source file: Звіт з переддипломної практики.md`

## Що це за промпт

Український промпт для визначення нестач точних даних, параметрів і джерел у матеріалах переддипломної практики.

## Для чого саме

Використовується для пошуку критичних прогалин перед написанням або фіналізацією звіту з переддипломної практики.

## Що можна отримати

- Список прогалин
- Чеклист відсутніх параметрів
- Питання для збору даних

## Очікувані результати

- Менше непідтверджених тверджень
- Чіткіший план збору даних
- Краща готовність звіту

## Що підготувати

- Прикріплені файли практики
- Цільовий продукт/процес
- Наявні джерельні дані

## Як використовувати

- Відкрийте потрібну мовну версію.
- Скопіюйте блок промпту повністю.
- Додайте файли або посилання, які промпт очікує як вхідні дані.
- Після першого запуску уточніть змінні, які модель попросить конкретизувати.

Проаналізуй прикріплені файли.
Твоє завдання визначити критичні точки нестачі даних (точні показники, технологічні параметри, числа до відсотків), які невистачатиме при генерації звіту з переддипломної практики та згенерувати відповідні пошукові chain of prompts для розкриття звіту у повному обсязі. Не вважай за можливість замінити з власної бази точні критичні дані - скористайся генерацією запитів chain of prompts для іншої моделі ШІ. Має бути розкритий кожний технологічний показник.
Вхідні дані для генерації - прикріплені файли: 
- `Курсова_робота_Клименко_М_А_БТ_3_1_1 (2).pdf` - для розділу 2.
- `Звіт з практики Фармак_Клименко М.А._БТ-4-1.pdf` - для розділу 3.

Виконай завдання у два кроки: (1) планування та пошук критичних даних, (2) генерація пошукових chain of prompts для іншої моделі ШІ (6 промптів), при генерації іншою моделлю відповідей, мають бути цитування джерел у стилі (автор, рік). Максимальна кількість джерел за одним промптом з chain of prompts - 4.

ВИСНОВКИ"""

На кожний розділ має бути два окремих запити від мене "далі". Максимально деталізуй технологічні та виробничі параметри, якщо цього потребує контекст. цитуй у тексті використані джерела, як (автор, рік).
Без булетів та без зайвих "привітань" і "звітності про виконання завдання".
