# Промпт витягу із самостійної роботи

`Language: UK` `Промпти для витягу` `Source file: Самостійна робота_для витягу.md`

## Що це за промпт

Український промпт для витягу вибраних розділів із самостійної роботи.

## Для чого саме

Використовується для збереження точного джерельного тексту для подальшого академічного збирання або аналізу.

## Що можна отримати

- Дослівні витяги
- Збережене форматування
- Повторно використовуваний джерельний текст

## Очікувані результати

- Чистіший подальший синтез
- Менше спотворення джерела
- Краща простежуваність

## Що підготувати

- Файл самостійної роботи
- Цільові розділи

## Як використовувати

- Відкрийте потрібну мовну версію.
- Скопіюйте блок промпту повністю.
- Додайте файли або посилання, які промпт очікує як вхідні дані.
- Після першого запуску уточніть змінні, які модель попросить конкретизувати.

## Промпт

<details open>
<summary>Текст промпту</summary>

~~~markdown
Ти працюєш з файлом "САМОСТІЙНА РОБОТА...". 
Твоє завдання — витягти вказані нижче розділи тексту без змін, зберігши оригінальне форматування, у форматі MD.

Витягни наступні частини:
1. "РОЗДІЛ №1. Шлях катаболізму ростового субстрату у..." (повністю). Це піде у РОЗДІЛ 4 (п. 4.1) фінальної роботи.
2. "РОЗДІЛ № 2. Біотрансформація ростового субстрату у..." (повністю). Це піде у РОЗДІЛ 4 (п. 4.2) фінальної роботи.

ВАЖЛИВА УМОВА: У тексті цих розділів є посилання на літературу у квадратних дужках (наприклад, [1], [2]). Ти повинен зберегти ці номери у тексті без жодних змін. Після витягнутого тексту створи заголовок "СПИСОК ВИКОРИСТАНИХ ДЖЕРЕЛ ДЛЯ ЦЬОГО БЛОКУ" і випиши туди з оригінального списку літератури (який є в кінці документа) ТІЛЬКИ ті джерела, номери яких зустрічаються у витягнутому тобою тексті. Бібліографічний опис джерел залишай в оригінальному вигляді без змін.
~~~

</details>
